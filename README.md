# BlendGo — навчальний товарний лендинг

## Структура
- `index.html` — HTML-розмітка сторінки
- `css/style.css` — стилі та адаптивна верстка
- `js/main.js` — форма замовлення, калькуляція та демонстраційні події аналітики

## Запуск
Відкрий `index.html` у браузері або запусти локальний сервер із кореневої папки проєкту.

## Перед реальним запуском
1. Замініть демонстраційний товарний контент, ціну, характеристики й відгуки на перевірені дані.
2. У `js/main.js` замініть `YOUR_META_PIXEL_ID` на реальний Meta Pixel ID та додайте офіційний базовий код Meta Pixel.
3. Налаштуйте GA4/GTM через реальні ідентифікатори та перевірте події в режимі налагодження.
4. Підключіть серверний endpoint або CRM webhook для реальної передачі заявок. Не зберігайте секретні ключі у frontend-коді.
5. Перевірте політику конфіденційності, згоду на обробку персональних даних, доставку, оплату та повернення.

**Увага:** форма зараз працює в демонстраційному режимі: вона перевіряє дані та показує підтвердження, але не надсилає замовлення на сервер. Відгуки, ціна та характеристики в макеті умовні.
